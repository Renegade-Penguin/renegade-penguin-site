# Partner logo provenance

Only two organizations publish an official logo kit whose terms allow this use, so only two logos are
shipped. The other six organizations on the site (NetJets, Henry Schein, GC Dental, SML Labs, Call Theory,
Call Center Village) are shown as styled text; no logo of theirs is downloaded, traced or recreated.

Each file below is served from the site's own origin, is the original bytes as published, and is shown
with no recolor, filter, opacity, blend, crop or pixel resize (CSS width and height only).
`scripts/test-logos.sh` fails when a file under `static/brand/partners/` has no entry here or its sha256
differs. Keep the entry format: a `## slug` heading and one `- Key: value` line per field.

- Path: `static/brand/partners/lorikeet-security.png`
- Source: https://lorikeetsecurity.com/images/lorikeet-logo-banner.png

- Type: PNG, RGBA, white logotype on a transparent background, for dark backgrounds
- Size: `695x216`
- Terms: Lorikeet's brand guidelines (https://lorikeetsecurity.com/brand-guidelines) offer this file for dark backgrounds and forbid recoloring, gradients, shadows and 3D effects, placing the white logo on a light background, a horizontal lockup narrower than 140 px, and less clear space than the shield height on all four sides.
- Altered: used unaltered
