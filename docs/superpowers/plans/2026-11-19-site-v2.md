# Renegade Penguin site v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Take the merged draft site to a buyable site: look C, a three-tier offer with published ranges, process and proof pages, trust and legal pages, a contact intake with Turnstile on one page, segment and Ohio pages, and the cross-link design.

**Architecture:** Same Hugo stack and checks as the merged build. New content is Markdown under `content/`; prices live in one data file rendered by one shortcode; the only script exception is the contact page, enforced by the existing check scripts extended with per-route rules and fixtures. Each task is its own branch and PR.

**Tech Stack:** Hugo 0.168.0, POSIX shell and Python 3 stdlib checks (run with `-I`), Playwright screenshots outside the repo, Cloudflare Worker (JavaScript, contact only), GYST workflows.

**Spec:** `docs/superpowers/specs/2026-11-19-site-v2-design.md`. The Global Constraints of `docs/superpowers/plans/2026-11-18-renegade-penguin-site.md` still bind every task (dark only, tokens, strict CSP, no em dashes, forbidden content, copyright line, 1920x930 fit for short pages), except where the exception below says otherwise.

## Global Constraints

- Look reference: `~/.local/share/renegade-penguin-site-dev/mockups/c/index.html` and `shots/c.png`. The lead compares rendered output to it side by side before reporting or merging.
- Exception, contact page only: one `<script src="https://challenges.cloudflare.com/turnstile/v0/api.js" async defer>` and one Turnstile container. CSP for `/contact/` adds exactly `script-src https://challenges.cloudflare.com; frame-src https://challenges.cloudflare.com; connect-src 'self'` (verify the exact directives from Cloudflare's Turnstile docs, date them in the task report) and `form-action` to the Worker's own origin. Every other route keeps the strict CSP.
- Claims language: "aligned to" frameworks (NIST CSF, CIS Controls, ISO 27001, HIPAA Security Rule). Never "certified", "compliant" (as a promise), "guarantee", "100%", "never failed". No named credential unless the owner confirms it.
- Prices exist only in `data/pricing.toml` and appear on pages only through the `pricing` shortcode. Values are proposals until the owner signs off.
- Public copy is written by ChatGPT through Codex and placed verbatim; the owner approves each page before its PR merges.
- Branch per task, PR linking its issue, `CI green` required, merged by the owner's word through the head-pinned path. Implementers: Sonnet, targeted checks only.

## Review Focus

- A script anywhere but `/contact/`, or an off-site URL other than the Turnstile origin: Task 4 fixtures fail the check for each.
- A dollar figure typed into a page instead of the data file: Task 2 check fails it.
- A banned claim word ("guarantee", "certified", "100%", "compliant" as a promise) in any page: Task 2 check with fixtures.
- Contact form with JavaScript disabled: the page still shows the mailto and PGP fallback and the incident notice. Task 4 test.
- Stale or placeholder content (year in footer, `#` links, lorem): Task 5 check fails it.
